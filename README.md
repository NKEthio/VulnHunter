# VulnHunter
Find and document your website's vulnerability using top tier tools

## Free tools to identify website vulnerabilities

- **OWASP ZAP** — Free and open-source web application security scanner for automated and manual testing.
- **Nikto** — Free web server scanner for dangerous files, outdated software, and known server issues.
- **Nmap + NSE scripts** — Free network and service scanner that can detect exposed services and common weaknesses.
- **SQLMap** — Free tool focused on detecting and exploiting SQL injection vulnerabilities.
- **Wapiti** — Free command-line scanner for common web vulnerabilities (XSS, SQL injection, file disclosure, and more).
- **Arachni Community Edition** — Free web application security scanner with strong crawl and audit capabilities.
- **OpenVAS (Greenbone Community Edition)** — Free vulnerability scanner for broader infrastructure and web-related weaknesses.
- **WPScan** — Free (community) scanner for WordPress security issues, vulnerable plugins, and weak configurations.
